# Hey, I'm Timur 👋

**AI Engineer** based in Russia.

I design and build AI-powered systems, with a particular focus on **autonomous agents, multi-agent architectures, and orchestration**.

My work spans the entire engineering lifecycle — from exploring ideas and designing architectures to building prototypes, integrating services, and delivering working solutions.

Currently, I'm particularly interested in how AI agents can **collaborate, coordinate, use tools, and solve complex problems together**.

### 🔭 What I'm working on

- **Multi-Agent Systems** — collaboration, communication, orchestration, and workflows.
- **Harness Engineering** - building business-products with around agentic harnesses.
- **Agentic Software Engineering** — exploring autonomous development teams, agent coordination, and AI-driven software delivery.
- **AI Safety & Security** — guardrails, prompt injection defense, and secure agent workflows.
- **Applied AI** — turning experimental ideas into practical, usable systems.
